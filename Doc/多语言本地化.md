# 多语言本地化

> 基线：NewLife.Core 12 编译期词表｜运行时 31 种语言｜英文为源文与兜底

## 2. 词表文件

- `NewLife.Audio/Locales`

- 文件名即 BCP 47 语言代码；英文是源文与兜底，**不需要** `en.yml`。
- 键为**英文原文**，必须与代码字符串逐字一致（含空格与标点）；占位符 `{0}` 与格式说明符 `{1:n0}` 必须与英文一致。
- 词表由 NewLife.Core 包内的源生成器在编译期读取并生成压缩语言表，NativeAOT 下同样可用。

## 3. 新增一条消息

1. 代码中写英文源文：`throw new XException("Session {0} is closed.", sessionId);`，日志直接写英文模板（`Logger.Format` 自动翻译）。
2. 在全部语言文件的同一位置补齐该键；遗漏只回退英文，不会编译失败。
3. 运行校验脚本确认键集合、占位符与格式说明符一致。

## 4. 校验

```powershell
# 运行时消息不得含中文（异常、日志、控制台、界面提示等调用点）
pwsh -File tools/check-english-exceptions.ps1

# 词表键集合、占位符与格式说明符一致，且无孤儿键
pwsh -File tools/check-locales.ps1 -LocaleDir NewLife.Audio/Locales -SourceDir NewLife.Audio
```

CI 的 localization job 会执行同一脚本。

## 5. 带前缀日志

日志消息同样写英文模板，由 NewLife.Core 的日志器按当前语言翻译。需要拼接实例前缀时，用 `InfoPrefixed` / `ErrorPrefixed` / `WritePrefixed`，前缀不参与查表：

```csharp
XTrace.Log.InfoPrefixed("WaveOut: ", "waveOutOpen returned {0}; falling back to the null player.", result);
```

不要把前缀和模板先拼成一整串再交给日志（如 `XTrace.WriteLine("WaveOut: " + ...)`），否则整串查不到词条，永远输出英文。
