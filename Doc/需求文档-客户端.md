# AudioStudio 客户端需求文档

> 版本：v1.0 | 日期：2026-07-14

AudioStudio 是基于 NewLife.Audio 库的 Avalonia 桌面演示客户端，用于展示和验证库的音频能力。

## 1. 背景与愿景

### 1.1 系统定位
AudioStudio 是一个**音频演示与工具客户端**，面向 NewLife.Audio 的使用者和开发者，提供直观的图形界面来展示库的编解码、设备 I/O、DSP 处理、录制、容器格式等核心能力。

### 1.2 愿景
- **开箱即用的演示工具**：安装后即可播放常见音频格式、查看文件信息、转换格式
- **音频诊断工具箱**：设备枚举与测试、PCM 数据分析、RTP 包解析
- **DSP 效果体验平台**：直观调节均衡器、滤镜、变速变调，实时感受效果
- **录制工具**：麦克风录制 → 保存为 WAV 文件
- **语音合成实验台**：切换离线/在线引擎与参数，逐项验证 TTS 的播报、保存与流式用法

## 2. 核心功能

### PLAY 音频播放与信息查看
- 支持打开 WAV/MP3/FLAC/OGG/MP4 等常见音频格式
- 播放控制：播放、暂停、停止、进度拖拽、音量调节
- 音频信息显示：采样率、位深、声道数、编码类型、时长、码率
- 元数据显示：标题、艺术家、专辑、风格、年份
- 播放列表管理：添加文件/文件夹、拖拽排序、删除、双击播放
- 上一首/下一首切换

### CONV 格式转换
- 单文件格式互转（WAV/MP3/AAC/OGG/FLAC/M4A）
- 批量转换（多文件队列）
- 转换进度显示
- 转换历史记录

### DEVICE 音频设备 I/O
- 枚举输出/输入设备
- 设备详细信息（名称、ID、支持格式）
- 播放测试音（正弦波，可调频率/音量/时长）
- 录制测试
- 驱动切换（自动/waveout/wasapi/asio）

### REC 音频录制
- 从麦克风录制 PCM 音频
- 可配置采样率（8k~48kHz）、声道（单声道/立体声）、位深（8/16/32 bit）
- 实时电平表显示
- 保存为 WAV 文件

### DSP 处理
- 音量控制与静音
- 声像（Pan）调节
- 三段均衡器（低音/中音/高音）
- 10 段图示均衡器（31Hz~16kHz）
- 低通/高通滤波器（可调截止频率）
- 变速与变调控制
- 频谱分析展示（真实 FFT：Hann/Hamming/Blackman 窗，1024 点）

### TOOL 编解码与诊断工具
- 编解码器注册表查看（名称、类型、有状态）
- PCM 十六进制数据查看与分析
- RTP 包解析与查看

### TTS 语音合成测试
- 六种引擎可选：系统语音（SAPI）、在线服务（HTTP）、子进程合成器（piper 等）、espeak-ng、macOS say、静音引擎
- 引擎参数就地配置：HTTP 地址/方法/请求体模板/请求头/返回类型，子进程可执行文件/参数模板/输出格式/采样率，espeak 与 say 的语速音量
- 三种主用法逐项验证：直接播报、保存 WAV/裸 PCM、流式合成并统计首包与分块
- 音色枚举与选择、语速/音量调节，支持单次覆盖与客户端默认值
- 高级能力：文本规范化（中文数字/英文读名/标点统一/分句）、磁盘缓存（命中统计与清空）、预生成语音库
- 一键「全部用法自检」，逐项输出 ✅/❌ 与耗时、字节数、RTF
- 生成结果可回放（WAV）并可直接打开输出目录

## 3. 🧊 暂缓清单

| 功能 | 暂缓理由 | 解冻前提 |
|------|----------|----------|
| 音频裁剪/拼接 | 涉及选区交互，UI 复杂度高 | 用户明确需求 |
| RTSP 流播放 | 需网络连接+流协议处理 | 库的 RtspClient 完善后 |
| ASIO 专属配置面板 | ASIO 驱动差异大 | 用户有 ASIO 设备需求 |
| 批量格式转换进度 | 当前单文件进度已实现 | 用户有批量需求时 |

## 4. 不做什么

- 不实现音频编辑（销毁性编辑超出演示工具范畴）
- 不做网络电台浏览器（Icecast 等）
- 不做 MIDI 相关功能
- 不做音效 VST 插件加载
