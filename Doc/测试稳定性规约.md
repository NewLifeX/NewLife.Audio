# 单元测试稳定性规约

> 目标：Windows / Linux / macOS / musl / 多指令集 CI **首跑即绿**，失败只代表真实缺陷。

## 1. 硬规则

| # | 规则 | 说明 |
|---|---|---|
| 1 | **不依赖外网与外部服务** | HTTP/RTSP 测试使用 `localhost` + 端口 `0` 或本地服务桩，不请求公网 |
| 2 | **不依赖主机字节序** | 构造二进制数据用 `BinaryPrimitives.Write*LittleEndian` 或 `SpanWriter` 显式端序，禁止用 `BitConverter.GetBytes` 生成协议数据 |
| 3 | **全局状态串行** | 改写 `Localization.Culture`、`XTrace.Log` 等进程级状态的用例放入 `GlobalState` 集合 |
| 4 | **等待用条件轮询** | 超时仅作防挂起兜底（≥5 秒），禁止固定 `Thread.Sleep` 作为唯一等待手段 |
| 5 | **平台差异显式跳过** | Windows P/Invoke（winmm/WASAPI/ASIO）用例在非 Windows 平台跳过或只测托管回退 |
| 6 | **端口与文件隔离** | 网络端口用 `0` 随机分配；文件用临时目录，测试结束清理 |

## 2. 运行矩阵

| 环境 | 覆盖 |
|---|---|
| Windows x64 | 全量单元测试 + NativeAOT 冒烟 |
| Linux x64 / arm64 | 全量单元测试 + NativeAOT 冒烟 |

| musl x64 / arm64 | Alpine 容器全量单元测试（观察期） |
| loongarch64 / riscv64 / s390x / arm32 | QEMU 仿真冒烟 |

工作流：[test.yml](../.github/workflows/test.yml)、[arch.yml](../.github/workflows/arch.yml)、[aot.yml](../.github/workflows/aot.yml)。

## 3. 失败处理

1. 先区分环境问题与真实失败：QEMU/仿真层崩溃（无 `=== ... passed` 汇总）会自动重试一次。
2. 真实失败必须修代码或修测试，不得用重试掩盖。
3. 多平台差异无法统一时，按平台拆分用例并用 `DisplayName` 标明。
