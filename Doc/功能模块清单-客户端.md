# AudioStudio 功能模块清单

> 版本：v1.0 | 日期：2026-07-14
> 需求文档：[需求文档-客户端](需求文档-客户端.md)

> 状态标记：✅ 已实现 | 🟡 部分实现 | 🔧 规划中 | ⏸ 暂缓 | ❌ 未开始

## M1 音频播放与信息查看

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| M1-1 | 音频文件打开与播放（WAV/MP3/FLAC/OGG/MP4） | ✅ | AudioContainerFactory + 编解码管线 |
| M1-2 | 播放控制（播放/暂停/停止/Seek/音量） | ✅ | Play/Pause/Stop + Slider 进度 + 音量滑块 |
| M1-3 | 音频信息面板（采样率、位深、声道、编码、码率） | ✅ | FormatInfoText 属性 |
| M1-4 | 元数据显示（标题、艺术家、专辑、封面） | ✅ | MetadataText 属性 |
| M1-5 | 播放列表（文件管理、拖拽排序、循环模式） | ✅ | ObservableCollection + PlaylistItem |
| M1-6 | 波形显示 | ✅ | Avalonia WaveformControl 自定义控件，实时PCM降采样波形绘制 |

## M4 音频录制

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| M4-1 | 麦克风录制并保存（WAV） | ✅ | DeviceService + AudioContainerFactory |

| M4-3 | 录制参数配置（采样率/位深/声道） | ✅ | ComboBox 选择 |

## M5 DSP 处理

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| M5-1 | 实时频谱分析 | ✅ | 真实 FFT 分析：Cooley-Tukey FFT + Hann/Hamming/Blackman 窗函数 |
| M5-2 | 图示均衡器（10 段） | ✅ | 31Hz~16kHz 滑块，±12dB |
| M5-3 | 音量/淡入淡出 | ✅ | 音量滑块 + 静音开关、3段均衡 |
| M5-4 | 音频滤镜（低通/高通） | ✅ | 可调截止频率，启用/禁用开关 |
| M5-5 | 变速变调 | ✅ | 0.25x~4x 独立控制 |
| M5-6 | DSP 管线编辑器 | ⏸ | 暂缓，需可视化串联多个 IAudioProcessor |

## M6 编解码与诊断工具

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
