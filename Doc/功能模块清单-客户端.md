# AudioStudio 功能模块清单

## PLAY 音频播放与信息查看

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| PLAY-1 | 音频文件打开与播放（WAV/MP3/FLAC/OGG/MP4） | ✅ | AudioContainerFactory + 编解码管线 |
| PLAY-2 | 播放控制（播放/暂停/停止/Seek/音量） | ✅ | Play/Pause/Stop + Slider 进度 + 音量滑块 |
| PLAY-3 | 音频信息面板（采样率、位深、声道、编码、码率） | ✅ | FormatInfoText 属性 |
| PLAY-4 | 元数据显示（标题、艺术家、专辑、封面） | ✅ | MetadataText 属性 |
| PLAY-5 | 播放列表（文件管理、拖拽排序、循环模式） | ✅ | ObservableCollection + PlaylistItem |
| PLAY-6 | 波形显示 | ✅ | Avalonia WaveformControl 自定义控件，实时PCM降采样波形绘制 |

## CONV 格式转换

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|

| CONV-3 | 音频参数调整（重采样/位深/声道） | ✅ | 格式参数UI：自定义采样率/位深/声道复选框+下拉列表 |
| CONV-4 | 转换进度与任务管理 | ✅ | IProgress + 历史记录列表 |

## DEVICE 音频设备 I/O

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| DEVICE-1 | 音频设备枚举 | ✅ | DeviceService + AudioBackendFactory |

| DEVICE-3 | 设备播放测试（测试音发生器） | ✅ | 正弦波发生器，可调频率/音量 |
| DEVICE-4 | 设备录制测试 | ✅ | Start/Stop 录制，电平监视 |

## REC 音频录制

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| REC-1 | 麦克风录制并保存（WAV） | ✅ | DeviceService + AudioContainerFactory |
| REC-2 | 系统环路录制 | ✅ | LoopbackRecorder 集成到 UI，环路录制模式开关 |
| REC-3 | 录制参数配置（采样率/位深/声道） | ✅ | ComboBox 选择 |
| REC-4 | 录制监视器（电平表） | ✅ | LevelColorConverter + LevelWidthConverter |

## DSP 处理

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| DSP-1 | 实时频谱分析 | ✅ | 真实 FFT 分析：Cooley-Tukey FFT + Hann/Hamming/Blackman 窗函数 |
| DSP-2 | 图示均衡器（10 段） | ✅ | 31Hz~16kHz 滑块，±12dB |
| DSP-3 | 音量/淡入淡出 | ✅ | 音量滑块 + 静音开关、3段均衡 |
| DSP-4 | 音频滤镜（低通/高通） | ✅ | 可调截止频率，启用/禁用开关 |
| DSP-5 | 变速变调 | ✅ | 0.25x~4x 独立控制 |
| DSP-6 | DSP 管线编辑器 | ✅ | 可视化处理器列表 + 添加/移除/排序/清空管线 |

## TOOL 编解码与诊断工具

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| TOOL-1 | 编解码器注册表查看器 | ✅ | 列表显示名称、AVTypes、有状态 |
| TOOL-2 | PCM 数据十六进制查看器 | ✅ | 输入 Hex → 解析显示样本统计 |
| TOOL-3 | RTP 包分析工具 | ✅ | 粘贴 Hex → 解析头字段 |
| TOOL-4 | VAD 测试工具 | ✅ | 多阶段信号生成 + GmmVad 实时检测 + 概率显示 + 日志 |
