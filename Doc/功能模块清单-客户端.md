## PLAY 音频播放与信息查看

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| PLAY-1 | 音频文件打开与播放（WAV/MP3/FLAC/OGG/MP4） | ✅ | AudioContainerFactory + 编解码管线 |
| PLAY-2 | 播放控制（播放/暂停/停止/Seek/音量） | ✅ | Play/Pause/Stop + Slider 进度 + 音量滑块 |
| PLAY-3 | 音频信息面板（采样率、位深、声道、编码、码率） | ✅ | FormatInfoText 属性 |
| PLAY-4 | 元数据显示（标题、艺术家、专辑、封面） | ✅ | MetadataText 属性 |
| PLAY-5 | 播放列表（文件管理、拖拽排序、循环模式） | ✅ | ObservableCollection + PlaylistItem |
| PLAY-6 | 波形显示 | ✅ | Avalonia WaveformControl 自定义控件，实时PCM降采样波形绘制 |

## MIDI 音序

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| MIDI-1 | 打开 MIDI 与内置示例 | ✅ | `OpenFilePicker` + `avares://AudioStudio/Assets/Midi/*.mid`；解析并渲染为 PCM |
| MIDI-2 | 波形与迷你钢琴卷 | ✅ | `MidiWaveformControl`：渐变 min/max 包络、RMS 线、节拍/小节网格、发光播放头、只读钢琴卷 |
| MIDI-3 | 播放控制 | ✅ | `MidiPlaybackService`：播放/暂停/停止/定位/音量，播放头同步 |
| MIDI-4 | 另存 WAV/MP3 | ✅ | 渲染结果经 `AudioFile.WritePcm` 输出 |

## CONV 格式转换

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| CONV-1 | 单文件格式互转 | ✅ | ConversionService 逐帧编解码转换 |
| CONV-2 | 批量格式转换 | ✅ | 异步批量队列 |
| CONV-3 | 音频参数调整（重采样/位深/声道） | ✅ | 采样率用 Sinc 档重采样，声道走 `ChannelConverter`、位深走 `PcmConverter` 真正转换数据；目标格式以源格式为基线只覆盖指定项，转换页已有参数 UI（采样率/声道/位深） |
| CONV-4 | 转换进度与任务管理 | ✅ | IProgress + 历史记录列表 |

## DEVICE 音频设备 I/O

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| DEVICE-1 | 音频设备枚举 | ✅ | `DeviceService` 经 `AudioDriverFactory.Create()` 运行时选择真实驱动（Windows 默认 WinMM，可显式选 WASAPI），设备列表来自 `IMMDeviceEnumerator`/`waveInGetNumDevs` 真实枚举 |
| DEVICE-2 | 设备详细信息（名称、ID、支持格式） | ✅ | AudioDeviceInfo + 格式信息显示 |
| DEVICE-3 | 设备播放测试（测试音发生器） | ✅ | 正弦波发生器，可调频率/音量 |
| DEVICE-4 | 设备录制测试 | 🟡 | Start/Stop 与电平监视已接真实采集器（库侧 `NullRecorder` 兜底已移除）；剩余为真实麦克风环境的端到端实测 |

## REC 音频录制

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| REC-1 | 麦克风录制并保存（WAV） | 🟡 | `DeviceService` + `AudioContainerFactory` 已接真实录制器，可存 WAV/其他容器；剩余为真实麦克风环境的实测 |
| REC-2 | 系统环路录制 | ✅ | `LoopbackRecorder` 走 WASAPI loopback 真实回采，库侧已有真实回采断言测试通过（FIX-006 已闭环） |
| REC-3 | 录制参数配置（采样率/位深/声道） | ✅ | ComboBox 选择 |
| REC-4 | 录制监视器（电平表） | ✅ | 电平取自真实采集数据（`AudioLevel.Measure` 算峰值，峰值保持 + 指数衰减平滑），库侧电平测量有单元测试 |

## DSP 处理

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|

| DSP-2 | 图示均衡器（10 段） | ✅ | 31Hz~16kHz 滑块，±12dB |
| DSP-3 | 音量/淡入淡出 | ✅ | 音量滑块 + 静音开关、3段均衡 |
| DSP-4 | 音频滤镜（低通/高通） | ✅ | 可调截止频率，启用/禁用开关 |
| DSP-5 | 变速变调 | ✅ | 0.25x~4x 独立控制 |
| DSP-6 | DSP 管线编辑器 | ✅ | 可视化处理器列表 + 添加/移除/排序/清空管线 |
