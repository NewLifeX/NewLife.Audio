## PLAY 音频播放与信息查看

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| PLAY-1 | 音频文件打开与播放（WAV/MP3/FLAC/OGG/MP4） | ✅ | AudioContainerFactory + 编解码管线 |
| PLAY-2 | 播放控制（播放/暂停/停止/Seek/音量） | ✅ | Play/Pause/Stop + Slider 进度 + 音量滑块 |
| PLAY-3 | 音频信息面板（采样率、位深、声道、编码、码率） | ✅ | FormatInfoText 属性 |
| PLAY-4 | 元数据显示（标题、艺术家、专辑、封面） | ✅ | MetadataText 属性 |
| PLAY-5 | 播放列表（文件管理、拖拽排序、循环模式） | ✅ | ObservableCollection + PlaylistItem |
| PLAY-6 | 波形显示 | ✅ | Avalonia WaveformControl 自定义控件，实时PCM降采样波形绘制 |

## CONV 格式转换

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| CONV-1 | 单文件格式互转 | ✅ | ConversionService 逐帧编解码转换 |
| CONV-2 | 批量格式转换 | ✅ | 异步批量队列 |
| CONV-3 | 音频参数调整（重采样/位深/声道） | 🟡 | `ConversionService` 只对采样率做重采样；声道/位深仅写进容器头、未转换数据（转换页当前也无参数 UI，见 FIX-008） |
| CONV-4 | 转换进度与任务管理 | ✅ | IProgress + 历史记录列表 |

## DEVICE 音频设备 I/O

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| DEVICE-1 | 音频设备枚举 | 🟡 | `DeviceService` + `AudioDriverFactory`；net8/net10 默认落到回退驱动，设备列表为伪造单条，需显式选择 WaveOut（见库 FIX-005） |
| DEVICE-2 | 设备详细信息（名称、ID、支持格式） | ✅ | AudioDeviceInfo + 格式信息显示 |
| DEVICE-3 | 设备播放测试（测试音发生器） | ✅ | 正弦波发生器，可调频率/音量 |
| DEVICE-4 | 设备录制测试 | 🟡 | Start/Stop 与电平监视已接，但默认"自动"驱动下录制器为空实现（见库 FIX-005） |

## REC 音频录制

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| REC-1 | 麦克风录制并保存（WAV） | 🟡 | `DeviceService` + `AudioContainerFactory`；默认驱动下录音器为 `NullRecorder`，需先切到 WaveOut（见库 FIX-005） |
| REC-2 | 系统环路录制 | 🟡 | `LoopbackRecorder` 已接 UI，但底层为正弦波模拟，真实系统声音回采需 WASAPI loopback（见库 FIX-006） |
| REC-3 | 录制参数配置（采样率/位深/声道） | ✅ | ComboBox 选择 |
| REC-4 | 录制监视器（电平表） | 🟡 | `LevelColorConverter` + `LevelWidthConverter` 已接 UI，但 `MonitorLevel` 用随机数模拟，未读真实采集电平 |

## DSP 处理

| 编码 | 功能 | 状态 | 说明 |
|------|------|:----:|------|
| DSP-1 | 实时频谱分析 | ✅ | 真实 FFT 分析：Cooley-Tukey FFT + Hann/Hamming/Blackman 窗函数 |
| DSP-2 | 图示均衡器（10 段） | ✅ | 31Hz~16kHz 滑块，±12dB |
| DSP-3 | 音量/淡入淡出 | ✅ | 音量滑块 + 静音开关、3段均衡 |
| DSP-4 | 音频滤镜（低通/高通） | ✅ | 可调截止频率，启用/禁用开关 |
| DSP-5 | 变速变调 | ✅ | 0.25x~4x 独立控制 |
| DSP-6 | DSP 管线编辑器 | ✅ | 可视化处理器列表 + 添加/移除/排序/清空管线 |

## 待修复项

> 客户端专属工单；库侧缺陷见[功能模块清单](功能模块清单.md)的 FIX-/IMP- 条目。

| 编号 | 严重程度 | 是什么问题 | 有什么危害 | 怎么修改 | 修改后的遗憾 | 触发路径 |
|---|---|---|---|---|---|---|
| FIX-008 | 建议 | `ConversionService` 把用户目标格式（声道/位深）写进容器头，但只对采样率做重采样，不转换声道与位深 | 一旦转换页开放参数入口或调用方传入 `targetFormat`，导出的 WAV 头与 PCM 数据不一致（时长/声道错乱、播放异常） | 要么补齐声道/位深转换（复用 `ChannelConverter`/`BitDepthConverter` 的静态助手），要么在转换时强制用实际数据格式覆盖目标格式；补齐后恢复转换页参数 UI | 补齐转换会增加一次数据拷贝与耗时；仅强制覆盖则参数 UI 仍不可用 | 调用 `ConversionService.ConvertFileAsync(..., targetFormat: new AudioFormat { Channels = 1, BitsPerSample = 32 })` |
