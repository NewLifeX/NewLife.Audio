# MIDI 示例曲目

本目录的 `.mid` 文件由 `Samples/MidiDemo` 的 `gen` 命令生成，用于 AudioStudio 的 MIDI 页面演示与测试。

| 文件 | 旋律来源 | 版权状态 |
|---|---|---|
| `ode-to-joy.mid` | 贝多芬《欢乐颂》 | 公有领域 |
| `greensleeves.mid` | 英国传统民谣《绿袖子》 | 公有领域 |
| `canon-in-d.mid` | 帕赫贝尔《卡农》 | 公有领域 |
| `jasmine-flower.mid` | 中国民歌《茉莉花》 | 公有领域 |

编曲由本项目生成，随项目以 MIT 许可证发布。不包含任何受版权保护曲目的旋律或转录。
