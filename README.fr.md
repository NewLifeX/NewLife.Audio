NewLife.Audio fournit des codecs et du streaming pour PCM, ADPCM, G.711, G.722, WAV et AAC, adaptés aux communications vocales et aux médias.

## Installation

```bash
dotnet add package NewLife.Audio
```

## Démarrage rapide

```csharp
var codec = new G711Codec();
var pcm = codec.Decode(encoded);
```

## Fonctionnalités

- Capacités de streaming et de communication temps réel
- Multiplateforme : Windows, Linux, macOS et ARM64/LoongArch64
- Implémentation entièrement managée sans dépendances natives
