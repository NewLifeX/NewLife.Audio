Uma biblioteca de processamento de áudio .NET multiplataforma e totalmente gerenciada, com suporte a codecs, E/S de dispositivos, efeitos DSP, processamento de fala, E/S de formatos de contêiner e streaming — tudo em um único pacote NuGet.

🎧 Cliente de demonstração desktop multiplataforma [AudioStudio](AudioStudio/) (Avalonia) incluído, com seis módulos de ferramentas: reprodução, conversão, dispositivos, gravação, DSP e diagnóstico.

Fonte: https://github.com/NewLifeX/NewLife.Audio  
NuGet: `NewLife.Audio`

## Recursos

### 🎵 Mecanismo de codecs (CODEC)
Conversão bidirecional de PCM para mais de 10 codecs de áudio, tudo em C# puro e gerenciado:
- **G.711** μ-law / A-law
- **G.722** / **G.726** ADPCM de sub-banda
- **IMA ADPCM** (DVI4)
- **Opus** (implementação CELT totalmente gerenciada)
- **MP3** (decodificação Huffman + desquantização inversa + IMDCT + síntese de sub-bandas)
- **AAC-LC** (análise ICS + decodificação Huffman + IMDCT + sobreposição e soma de janelas)
- **FLAC** (LPC fixo + codificação residual Rice + MD5)
- **Ogg Vorbis** (codificação/decodificação de 3 pacotes de cabeçalho)
- **Speex** (CELP de banda estreita totalmente gerenciado)
- Fábrica plugável via `CodecRegistry` + metadados `ICodecInfo`
- Adaptação de cabeçalhos de chips de IoT (Hisilicon / Dahua / Uniview)

### 🔊 E/S de dispositivos de áudio (DEVIO)
Abstração de dispositivos de áudio multiplataforma:
- Enumeração e descoberta de dispositivos
- Backends **WaveOut** / **WASAPI** / **ASIO** no Windows
- Captura de áudio e gravação de loopback
- Gerenciamento simultâneo de vários dispositivos via `AudioDeviceManager`

### 🎛️ Pipeline de DSP (DSP)
Cadeia de processamento de sinais de áudio composável:
- Reamostragem (interpolação linear)
- Conversão de canais (mono ↔ estéreo)
- Conversão de profundidade de bits / formato de amostra (8/16/32 bits ↔ float)
- Controle de volume e ganho (linear / logarítmico)
- Mixagem multifonte com normalização
- Análise espectral **FFT** (Cooley-Tukey, janelas Hann/Hamming/Blackman)
- **Equalizador** (gráfico de 10 bandas + tom de 3 bandas, cascata BiQuad)
- **Filtro BiQuad** (padrão RBJ: LP/HP/BP/Notch/Peaking/LowShelf/HighShelf)
- Compressor de faixa dinâmica (soft-knee, envelope RMS)
- Fade in/out e crossfade (linear/log/cosseno)
- Mudança de velocidade (OLA) e mudança de tom (pitch shift)
- `IAudioProcessor` encadeável + `AudioPipeline`

### 🗣️ Processamento de fala (VOP)
Front-end de comunicação de voz em tempo real:
- **VAD** — Detecção de atividade de voz (modelo GMM, 6 sub-bandas + hangover)
- **AEC** — Cancelamento de eco acústico (filtro adaptativo NLMS + detecção de fala dupla + ruído de conforto)
- **AGC** — Controle automático de ganho (ataque lento e liberação rápida, envelope RMS)
- **NS** — Supressão de ruído (subtração espectral + FFT/IFFT + síntese OLA)
- Pipeline de pré-processamento de voz: HPF → VAD → AGC

### 📦 Formatos de contêiner (CONT)
Leitura e gravação de arquivos de áudio:
- **WAV** — Análise e gravação completas de RIFF
- **Ogg** — Leitura/gravação em nível de página (Opus/Vorbis)
- **MP4/M4A** — ISO BMFF: análise e geração de caixas ftyp/moov/mdat
- **FLAC** — Análise nativa de blocos de metadados fLaC
- **PCM bruto** — Detecção automática ou especificação manual do formato

### 📡 Streaming e transporte (STRM)
Streaming de áudio em rede:
- **RTP** — empacotamento e desempacotamento de pacotes (RFC 3550) + gerenciamento de sessão
- Cliente **RTSP** (TCP: OPTIONS→DESCRIBE→SETUP→PLAY→TEARDOWN, análise de SDP)
- Streaming de áudio **HTTP** (Icecast/SHOUTcast)
- Tubo de áudio bidirecional **WebSocket** (cabeçalho de quadro de 5 bytes)

## Instalação

```bash
dotnet add package NewLife.Audio
```

## Início rápido

```csharp
using NewLife.Audio;
using NewLife.Audio.Codecs;

// Decodifica G.711 μ-law para PCM
var codec = new G711UCodec();
var pcm = codec.ToPcm(encodedData);

// Codifica PCM para G.711 A-law
var g711a = new G711ACodec();
var encoded = g711a.FromPcm(pcmData);
```
